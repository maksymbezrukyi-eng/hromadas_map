# Інструмент відбору громад

Уніфікований веб-інструмент для відбору та моніторингу громад у програмі «Delivery of universal Early Childhood Development services in primary health care» (UNICEF Ukraine × KfW).

## Використання

Відкрити: `https://maksymbezrukyi-eng.github.io/hromadas_map/`

Три вкладки:
- **◉ Карта** — 68 громад на інтерактивній карті з фільтрами по області та пошуком
- **▦ Дашборд** — KPI відбору, воронка (загальний список → рекомендовані → опитування → short-list → резерв), статус по областях, топ-20 за балом опитування, середні бали по доменах, розподіл балів, радар, зведення по областях
- **≡ Таблиця** — сортована таблиця з пошуком та фільтром по області

## Структура репозиторію

```
hromadas_map/
├── index.html               # Розмітка + підключення скриптів
├── README.md                # Документація та changelog
├── CLAUDE.md                # Технічний контекст проєкту (детальніше, ніж тут)
├── AGENTS.md                # Робочі правила для рефакторингу
├── css/style.css            # Стилі
├── js/                      # config.js, data.js, sheets.js, table.js, dashboard.js, map.js, app.js
├── scripts/
│   └── convert_workbook.ps1 # Конвертер Excel-воркбука відбору в data/*.json
└── data/
    ├── hromadas_68.geojson  # Межі громад
    ├── id_mapping.json      # Звірка нумерації громад (воркбук ↔ H[].id)
    └── hromadas_survey.json # Знімок реальних даних опитування
```

## Changelog

### v0.5 — 2026-08-28

**Довершено розбиття на модулі, джерело даних абстраговано, цифри й термінологія — під чинну методологію**

- `index.html` тепер лише розмітка — весь JS виведено в `js/config.js` (константи) і
  `js/app.js` (спільний стан, ініціалізація)
- Джерело даних перемикається однією константою `DATA_SOURCE` у `config.js` —
  `'sheets'` (Google Sheets, чинна поведінка) або `'local'` (знімок реальних даних з
  Excel-воркбука відбору, `data/hromadas_survey.json`, поки не ввімкнено за
  замовчуванням); обидва джерела звіряються з явним переліком очікуваних колонок при
  кожному завантаженні — відсутність колонки тепер видно в консолі й індикаторі
  синхронізації, а не мовчки ігнорується
- Новий `scripts/convert_workbook.ps1` — конвертер Excel-воркбука відбору в
  `data/*.json`, зі звіркою двох різних нумерацій громад (воркбук ↔ `H[].id`,
  `data/id_mapping.json`)
- "До оцінки" й воронка відбору на дашборді більше не хардкод "56"/"12 виключені
  UNICEF" — рахуються від реальних 68 громад, як і вимагає чинна методологія
  (опитування охоплює всіх, статус UNICEF не підстава для технічного виключення)
- Ціль short-list у воронці — "45", резерв — окремим рядком "5" (замість застарілого
  "відібрано, ціль 40")
- Домен 7 "Інституційний профіль" усюди підписаний правильно (раніше — "Д4А")
- Дефолтний статус UNICEF для громад до першої синхронізації — нейтральний "pending"
  (раніше — "recommended", що виглядало як готове рішення до початку опитування)

  лишились у коді як внутрішні дані — вони не показуються користувачу
